# Development workflow

- `main` is the source for the current Pi 5 installer and setup guides. Use the [release checklist](docs/RELEASE-REVIEW.md) for build and verification commands.
- Start with the current commit and inspect the relevant files and diffs. Use targeted searches and short excerpts. Keep full logs and generated artifacts in the workspace.
- Make small, independently verifiable changes. Record the checks run in the commit message and save approved milestones on the agreed branch.
- For a handoff, record the commit ID, pending local changes, and the next step. Resume from that checkpoint and the current diff.
